## Visualização do Curso

<b>Visualização do Curso</b> mostra o programa do curso: uma lista de lições com tarefas.

<style>
img {
  display: block;
  margin-left: auto;
  margin-right: auto;
}
</style>
<img src="edu_course_view.png" class="center" width="75%"/>

Você pode navegar para qualquer tarefa clicando duas vezes no nome da tarefa.

Para ocultar a janela de Visualização do Curso, clique no botão Janela de Ferramentas do Projeto ou pressione <span style="color: #509DD6">&shortcut:ActivateProjectToolWindow;</span>. Isso dará mais espaço para as janelas do Editor e da Descrição da Tarefa.

Para mostrar a janela de Visualização do Curso que estava oculta, clique novamente no botão Janela de Ferramentas do Projeto (ou pressione <span style="color: #509DD6">&shortcut:ActivateProjectToolWindow;</span>).
